
# 公开 SOP 数据源清单（Day01 收集时使用）

> 红线：只收集公开可访问的化学分析 SOP / 方法模板，绝不使用任何企业内部文件。

## 搜索入口

| 来源 | 链接 / 搜索词 | 能找到什么 |

|---|---|---|

| GitHub 搜索 | https://github.com/search?q=analytical+chemistry+SOP | 公开实验室 SOP 模板仓库 |

| GitHub 搜索 | https://github.com/search?q=lab+SOP+template | 通用实验室 SOP 模板 |

| WHO 实验室手册 | https://www.who.int （laboratory manual） | 公开实验室质量手册 |

## Day01 收集目标（预告）

- 收集 5–8 份公开化学分析 SOP PDF，优先覆盖：

  - ICP-MS / ICP-OES 操作

  - GC-MS 操作

  - 样品前处理（消解/萃取）

  - 实验室安全

- 对其中 1–2 份，自行构造"新旧两个版本"的模拟元数据（改版本号和生效日期），用于版本核查演示
